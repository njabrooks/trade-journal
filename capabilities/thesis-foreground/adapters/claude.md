## Claude Provider Adapter

1. This Capability is interactive-only. Confirm that the current user is actively participating in this repository session. If invoked headlessly, autonomously, from a schedule, cron, background process, batch, CI, webhook, timeout, or without a current user response, refuse immediately before reading thesis or repository state, loading the database, calling a provider, asking a follow-up question, or writing anything. Do not schedule or defer the request.
2. Require one explicit verb (`query`, `what-changed`, `observe`, `assess-evidence`, or `re-underwrite`) and one explicit macro or asset thesis. Resolve a supplied ticker, title, or ID through `npx tsx scripts/ops/thesis-snapshot.ts`; when the selector is absent, unknown, or ambiguous, return the error or candidates and obtain the user's exact target before invoking a dependency or writing.
3. Resolve `capability:scope:trade-journal/thesis-observation`, `capability:scope:trade-journal/thesis-underwriting`, and `capability:scope:trade-journal/belief-evidence-assessment` through the published Registry Lock and use their exact Claude adapters. Do not copy, reinterpret, or widen a dependency contract.
4. For `query`, answer conversationally from the selected snapshot's living underwriting, conviction history, active auto-derived signals, provenance-bearing claims and observations, signal-quality context, strategies, performance, and allocation. For `what-changed`, compare only against the latest articulation timestamp, separate newly created from newly linked claims, include observation or assessment evidence recorded since it, and state explicitly when no prior baseline or reliable timestamp exists. Both verbs are read-only.
5. For `observe`, pass only the exact thesis and explicit as-of time to the governed thesis-observation adapter. Preserve its Tier-1 monitoring and active-signal eligibility, current attributable source requirements, collector deferral, thesis-centric polarity, sensing-only writes, and honest unavailability. For supplied evidence, use the governed belief-evidence-assessment adapter; recording is off unless the current user explicitly requests it.
6. For `re-underwrite`, require the current user's explicit request for the exact thesis. Load the complete snapshot, refuse while `thin.unlinkedClaimCount` is non-zero or provenance, candidate-signal dispositions, signal-quality inputs, or target identity are incomplete, and explain that a new version supersedes the current resolution set. Obtain any remaining scope or disposition judgment, then delegate only to the governed thesis-underwriting adapter and its previewed bounded write path.
7. Return the thesis ID and type, verb, baseline, dependency calls, sources, summary, limitations, user judgments received, recording disposition, exact writes, and explicit refusal, unavailable, stale, or failure state. Never call a failed or partial result successful.

This adapter has no direct database authority. Its maximum writes are the exact writes returned by one selected governed dependency. It must not drain maintenance, create or resolve Decision Items, change entity status, configure manual signals or `explicit_details`, create claims, alter claim-thesis links, use ad-hoc SQL or generic writers, size or place trades, access credentials for convenience, install a provider, or create or change a schedule or launchd definition. It must never be declared unattended-current or eligible for headless or scheduled execution.
