## Pattern You're Replicating

The `UnifiedClaimsBrowser.tsx` pattern (463 lines) includes:

✅ **Advanced Filtering**: Multi-select dropdowns, search across fields  
✅ **Sortable Columns**: Click headers to sort, visual indicators  
✅ **Expandable Rows**: Click chevron to see full details  
✅ **Inline Actions**: Status changes, linking workflows (no page navigation)  
✅ **Keyboard Shortcuts**: `/` for search, `ESC` to close  
✅ **Empty States**: Helpful messages when no results

**Your New Browsers Will Have**:

```
UnifiedMacroThesisBrowser.tsx (~800 lines)
├─ Columns: Title, Type, Time Horizon, Confidence, Status, Asset Theses, Strategies
├─ Filters: Type, Time Horizon, Confidence, Status
├─ Search: Title, sectors, description
├─ Inline Linking: Asset Theses column → LinkToViewsDialog
└─ Expandable: Full description, sectors, claims, notes

UnifiedAssetThesisBrowser.tsx (~850 lines)
├─ Columns: Title, Underlying, Time Horizon, Confidence, Status, Macro Theses, Strategies
├─ Filters: Time Horizon, Confidence, Status, Underlying, Macro Thesis
├─ Search: Title, ticker, description
├─ Inline Linking: Macro Theses + Strategies columns → dialogs
└─ Expandable: Description, market data, claims, notes

UnifiedStrategiesBrowser.tsx (~900 lines)
├─ Columns: Strategy, Account, State Code, Status, Asset Theses, Abs Notional, Unrealized, % NAV
├─ Filters: Status (w/ "Show Closed" toggle), Account, Asset Thesis, Macro Thesis, State Code
├─ Search: Strategy label, key, underlying
├─ Inline Linking: Asset Theses column → LinkToViewDialog
└─ Expandable: Positions, recent actions, metrics, notes
```
